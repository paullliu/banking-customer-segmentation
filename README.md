# Banking Customer Segmentation

A banking analytics project exploring which merchant category and customer segment to prioritize for a new financial product.

## Business questions

1. Which merchant category offers a promising focus for the product?
2. How can customers be segmented using their transaction behavior?
3. Which segment should the product target, and what risks or tradeoffs should inform that choice?

## Dataset

Three linked datasets contain 5,645 customers, 11,290 accounts, and 92,304 transaction records spanning March–October 2018. They provide customer characteristics, account balances, and transaction amounts, dates, and merchant categories.

## Tools

PostgreSQL / SQL.

## Repository and data access

The `sql/` directory contains the analytical SQL. The [data guide](data/README.md) describes the expected source files and their relationships.

The original source data is not included in this repository.
